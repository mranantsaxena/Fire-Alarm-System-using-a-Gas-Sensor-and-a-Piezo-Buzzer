# Fire-Alarm-System-using-a-Gas-Sensor-and-a-Piezo-Buzzer
🔥 Smart Fire &amp; Gas Alarm System built with Arduino Uno. Uses LM35 (Temp) and MQ-2 (Smoke) sensors for real-time multi-hazard detection. Features a tiered alert system (Buzzer/LED) for gas leaks and heat spikes. Demonstrates analog signal processing, voltage dividers, and embedded C++ logic. Designed &amp; tested in Tinkercad.
